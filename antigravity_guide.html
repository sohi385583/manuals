Google Antigravity 活用ガイド

カテゴリー: AI Development Platform | 最終更新: 2026年9月24日

1. 概要・3つのサーフェス

Google Antigravity（AGY）は、Geminiを核としたAIファーストの開発プラットフォームです。コーディング、デバッグ、テスト、リサーチ、タスク管理まで、自律型エージェントと協調して開発を進められます。

Antigravityは主に以下の3つのサーフェス（動作環境）を提供しています：

  • Antigravity IDE: VS Codeをベースにした統合開発環境。エディタ上でコード補完、インライン編集、サイドバーエージェントがシームレスに動作します。
  • Antigravity 2.0: デスクトップアプリケーション。複数のプロジェクト管理、チャットキャンバス、サブエージェントやバックグラウンドタスクの統合監視が可能です。
  • Antigravity CLI (agy): ターミナルから軽量にエージェントを呼び出せるコマンドラインツール。シェルスクリプトやCI環境との親和性も高いインターフェースです。

2. 3つのAI操作モード

Antigravity IDEでは、作業内容や粒度に合わせて3つのインタラクションモードを使い分けます。

A. パッシブモード: Tab補完 (Autocomplete / Supercomplete)

キーストロークに合わせて、次に書くコードや修正内容を先回り予測して提案します。

  • Autocomplete: カーソル位置のコード行やブロックを補完。
  • Supercomplete: 複数行の削除・置換を含む大きな差分（diff）をプレビュー表示して提案。
  • Tab to Jump: 次に編集すべき関数や変数位置を予測し、Tab でジャンプ移動。
  • Tab to Import: 外部ライブラリや関数使用時に、ファイル上部に必要なインポート文を自動挿入。
  • 操作方法: 提案採用は Tab、破棄は Esc、1単語ずつ採用は ⌘+→（macOS） / Ctrl+→（Windows/Linux）。

B. 指示型モード: インライン編集 (⌘+I / Ctrl+I)

局所的なコード変更を直接指示するモードです。

  • 選択範囲のリファクタリング: コードを範囲選択して ⌘+I を押し、「エラーハンドリングを追加して」「型定義を厳格にして」と指示。
  • 新規コード生成: カーソル位置で ⌘+I を押し、「CSVパース関数を作成して」と指示。
  • ドキュメント生成: 関数全体を選択して「JSDoc形式で詳細なコメントを追加して」と指示。

C. 協調型モード: サイドバーチャット & エージェント

複数ファイルにまたがる機能実装、バグ調査、環境構築などの複雑なタスクを任せる自律型モードです。

  • 自律的なファイル操作・実行: ファイルの作成・置換、コマンド実行、ブラウザでの動作検証まで自動で実行。
  • プランニング機能: 実装に入る前に、手順と設計の計画（Plan）を提示してユーザーと合意形成。

3. スラッシュコマンド活用

チャット欄に / を入力することで、専門的なワークフローや専用動作を呼び出せます。

コマンド 機能説明と推奨用途
/plan 大規模な改修や新機能作成の前に、詳細なステップバイステップの計画を作成して提示させます。
/grill-me エージェントからユーザーに対して設計意図や仕様の深掘り質問を行い、要件のブレをなくします。
/learn 解決したトラブルやプロジェクト固有のルールをナレッジとして記憶させ、次回以降の作業に反映します。
/goal 目標達成まで徹底的に検証・反復を続けさせる長時間タスク向けの実行指示です。
/schedule 指定時間後のリマインダーや、定期的なバックグラウンド監視タスク（cron）をスケジュールします。

4. @メンションとコンテキスト

プロンプト入力時に @ を入力すると、エージェントに渡すコンテキストを明示的に指定できます。

  • @Files & Folders: 特定のファイルやディレクトリ（例: @index.html, @src/）を直接参照させます。
  • @Conversations: 過去のチャットセッションを指定して、前回の議論や決定事項を引き継ぎます。
  • @Terminals: ターミナルの直前の出力結果やエラーログをエージェントに直接読み込ませます。
  • @Rules / @Skills: 適用したいルールやカスタムスキルをピンポイントで呼び出します。
  • @MCP: 接続されたModel Context Protocol（MCP）サーバーや外部ツールを指定して呼び出します。

Tips: 画像やスクリーンショットもチャット欄へのドラッグ＆ドロップで直接貼り付けることができ、UIの不具合調査やデザイン再現に活用できます。

5. プロジェクトのカスタマイズ

Antigravityはプロジェクト固有のルールやカスタムツールを柔軟に設定できます。

Customization Roots（設定の配置場所）

  • グローバル設定: ~/.gemini/config/（PC全体の共通設定）
  • プロジェクト設定: .agents/（リポジトリごとの個別設定）

主な設定要素

  • Rules（行動規約・コーディング規約）:

    .agents/rules/ または GEMINI.md / AGENTS.md に記述します。エージェントがコードを書く際のフレームワーク制約、命名規則、コミットメッセージの書式などを指定します。

  • Skills（スキル・専門手順）:

    .agents/skills/<skill-name>/SKILL.md に定義します。リリース手順、テスト実行手順、特定のAPI利用規約などをエージェントが自動または手動でロードできるようにします。

  • MCP Servers（外部ツール連携）:

    mcp_config.json に記述し、GitHub、PostgreSQL、Playwrightなどの外部サーバーと連携してエージェントのツールを拡張します。

6. 設定・セキュリティ権限

エージェントが安全かつ快適に作業できるように、実行権限やアクセスポリシーを細かく調整できます。

Tool Execution Policy（コマンド実行承認）

  • always-proceed: コマンド実行を自動で許可し、素早く作業を進めるモード。
  • request-review: コマンド実行前にユーザーの承認を求める安全重視モード。
  • proceed-in-sandbox: 制限されたサンドボックス環境内で安全に自動実行するモード。

Access Controls（アクセス制御）

  • File Access Policy: ワークスペース外のファイルへのアクセス（allow / ask / deny）。
  • Internet Access Policy: Web検索やURLへのHTTPアクセスの許可（allow / ask / deny）。
  • Allowlist / Denylist: 実行を常時許可または禁止するコマンド・URLを指定。
