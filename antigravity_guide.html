Antigravity IDE 操作・活用マニュアル

カテゴリー: AI IDE & Editor | 最終更新: 2026年9月24日

1. Antigravity IDE 概要

Antigravity IDE は、VS Codeをベースに設計されたAIネイティブな統合開発環境です。エディタ内のキーストローク予測から、インラインでの部分リファクタリング、サイドバーでの自律型エージェントによるペアプログラミングまでが統合されています。

  • 直感的な操作感: 普段のVS Codeと同じ拡張機能やキーバインドをそのまま維持。
  • シームレスなAI連携: コード補完だけでなく、コンパイルエラーの自動修復やテスト生成を1クリックで実行可能。
  • 自律型ペアプログラミング: ファイル作成、修正、コマンド実行、ブラウザ検証までエージェントが自律的に対応。

2. 3つのAI操作モード

Antigravity IDEでは、作業の粒度や目的に応じて3段階のAI操作モードをシームレスに使い分けます。

A. パッシブ: Antigravity Tab（補完・先回り予測）

タイピング中に次の一手を予測し、1ストロークでコードを反映します。

  • Autocomplete: カーソル位置の単語、行、コードブロックを文脈に合わせてリアルタイム補完。
  • Supercomplete: カーソル周辺の複数行にわたる削除・置換を含む差分（Diff）を提案。
  • Tab to Jump: 次に編集すべき関数・引数・変数へ Tab でカーソルをジャンプ移動。
  • Tab to Import: 未定義のモジュールや型を使用した際、ファイル先頭に必要な import 文を自動挿入。

B. 指示型: インラインコマンド (⌘+I / Ctrl+I)

エディタの選択箇所に対してピンポイントで指示を出し、部分的にコードを書き換えるモードです。

  • 選択範囲のリファクタリング: 関数を選択して「TypeScriptの型安全性を高めて」「エラーハンドリングを追加して」と指示。
  • 新規コード生成: 空行でショートカットを押し、「入力バリデーション用の正規表現関数を作成して」と指示。
  • ドキュメント・コメント作成: 複雑なロジックを選択して「JSDocコメントを生成して」と指示。

C. 協調型: サイドバーチャット & 自律エージェント (⌘+L / Ctrl+L)

プロジェクト全体に関わる大規模な実装、機能追加、デバッグ、環境構築を対話形式で進めるモードです。

  • 複数ファイルの一括編集: 関連するコンポーネント、スタイル、テストコードを横断して作成・修正。
  • ターミナルコマンド実行: ビルド、テスト、パッケージインストールをエージェントが自動または確認付きで実行。
  • ブラウザ動作確認: 作成したWEBページの画面崩れやエラーをエージェント自身が確認して修正。

3. エディタ統合機能

Antigravity IDEならではのエディタ連携機能により、日常のコーディングを加速します。

Inline Code Lenses（インラインコードレンズ）

クラスや関数、メソッドの定義行の上に、AIアクションボタンが直接表示されます。

  • Refactor: よりシンプルで堅牢なコードへのリファクタリングを即座に開始。
  • Write Tests: 選択した関数に対する単体テスト（Unit Test）を自動生成。
  • Explain Code: ロジックの処理意図やアルゴリズムの解説を表示。

Visual Diff Overlays（ビジュアル差分プレビュー）

AIが生成したコードは、エディタ上にインラインで赤（削除）と緑（追加）の差分としてプレビュー表示されます。内容を確認した上で、ワンクリックまたはショートカットで承認（Accept）または破棄（Reject）できます。

Diagnostic Auto-Fix（エラー自動修正）

TypeScriptのエラー、ESLintの警告、コンパイルエラー箇所に表示される電球アイコンや「Problems（問題）」パネルから、エージェントを直接呼び出して自動修正させることができます。

5. コマンドと@メンション

サイドバーチャットで活用できるコマンドとコンテキスト指定方法です。

主要スラッシュコマンド (/)

コマンド 機能説明
/plan 実装前にファイル構成やステップごとの詳細計画を作成して確認します。
/grill-me エージェントから設計意図や要件の確認質問を行い、仕様のブレを防ぎます。
/learn 解決したエラーやプロジェクト独自のルールを記憶させ、今後の開発に活かします。
/goal タスク達成・テスト通過まで自律的に検証を繰り返す長時間実行指示です。

@メンションによるコンテキスト付与

  • @Files & Folders: 特定のファイルやディレクトリ（例: @index.html）を参照対象に指定。
  • @Terminals: ターミナルの直前のコマンド出力やエラーログをエージェントに読み込ませる。
  • @Conversations: 過去のチャットログを引き継いで作業を再開。
  • @Rules / @Skills: 定義済みのコーディング規約や手順書を明示的に適用。

6. プロジェクト設定と権限

プロジェクトのルートディレクトリに設定を配置することで、エージェントの挙動をカスタマイズできます。

ワークスペース固有の設定 (.agents/)

  • .agents/rules/:

    「TailwindCSSは使わずVanilla CSSを使用する」「コミットメッセージはConventional Commitsに準拠する」などのコーディング規約を記述します。

  • .agents/skills/:

    「デプロイ手順」「APIクライアントの生成手順」など、繰り返し実行する定型ワークフローを定義します。

ツール実行ポリシー（コマンド実行の承認設定）

IDEの設定（Settings）から、エージェントがコマンドを実行する際の挙動を制御できます：

  • request-review (推奨): ターミナルコマンドを実行する前にユーザーに確認・承認を求めるモード。
  • always-proceed: コマンド実行を自動で進め、スピーディに開発を行うモード。
  • proceed-in-sandbox: サンドボックス環境で安全に自動実行するモード。
