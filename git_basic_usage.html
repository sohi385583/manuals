GitHub / Git コマンドリファレンス

カテゴリー: Version Control | 最終更新: 2026年7月25日

1. 概要・用語整理

Gitはファイルの変更履歴を記録するバージョン管理システムであり、GitHubはチームや個人でソースコードを共有・管理するためのWebサービスです。

  • ローカルリポジトリ: 自分のPC内にある作業用リポジトリ
  • リモートリポジトリ: GitHub上にある共有リポジトリ（デフォルト名は origin）
  • コミット (Commit): ファイルの変更履歴を保存する単位
  • プッシュ (Push): ローカルのコミットをGitHubへ送信・反映する操作
  • プル (Pull): GitHubの最新状態を取得し、ローカルに統合する操作

2. リポジトリの準備

git clone （リポジトリの複製）

GitHub上の既存リポジトリをローカルPCにダウンロードして複製します。

# 指定したURLのリポジトリをカレントディレクトリに複製
git clone <リポジトリのURL>

# 現在のディレクトリ内に直接複製する場合（ディレクトリが空である必要があります）
git clone <リポジトリのURL> .

3. 日常のコマンド例

git status （状態確認）

現在編集されたファイルや、新規作成されて追跡されていないファイルの状態を確認します。

git status

git add （ステージング）

変更したファイルのうち、コミットに含めるものを選択（ステージ）します。

# 特定のファイルをステージング
git add path/to/file.html

# 変更または新規作成されたすべてのファイルを一括でステージング
git add .

git commit （コミット）

ステージングされた変更に対してメッセージを付け、ローカルリポジトリに履歴として記録します。

git commit -m "feat: 〇〇機能の追加"

git pull （最新状態の取得・統合）

GitHub（リモートリポジトリ）の最新状態を取得し、現在作業中のローカルブランチに自動でマージ（統合）します。

# originリモートの指定したブランチから最新状態を取得してマージ
git pull origin <ブランチ名>

# 例: mainブランチの最新状態を取り込む
git pull origin main

git push （リモートへの送信）

ローカルリポジトリで記録したコミットを、GitHub（リモートリポジトリ）に送信して反映します。

# 指定したブランチへ変更を送信
git push origin <ブランチ名>

# 例: mainブランチにプッシュする
git push origin main

注意: 他の人と共同開発を行っている場合は、作業前に必ず git pull を実行して最新のコードを取り込んでから開発を進めるようにしましょう。

4. ブランチ操作コマンド例

git branch （ブランチの一覧・確認）

現在存在するローカルブランチおよびリモートブランチの一覧を確認します。

# ローカルブランチの一覧を表示（現在選択されているブランチには * が付きます）
git branch

# リモートブランチを含むすべてのブランチを表示
git branch -a

git switch / git checkout （ブランチの切り替え・新規作成）

作業するブランチを切り替えます。または、新しくブランチを作成してそこに切り替えます。

# 既存のブランチへ切り替える
git switch <ブランチ名>
# （従来のコマンド表記）
git checkout <ブランチ名>

# 新しいブランチを作成して、同時にそのブランチへ切り替える
git switch -c <新しいブランチ名>
# （従来のコマンド表記）
git checkout -b <新しいブランチ名>

5. トラブル解決コマンド例

git commit --amend （直前コミットの修正）

直前に行ったコミットのメッセージを修正します。また、ステージングされた変更を直前のコミットに追加することもできます。

git commit --amend -m "修正後の正しいコミットメッセージ"

git restore （変更の取り消し）

誤って変更してしまったファイルを元に戻したり、ステージングしたファイルを取り消したりします。

# ステージングしたファイルを取り消す（ワークスペース内のファイルの編集内容は維持）
git restore --staged <ファイル名>

# ファイルの編集内容自体を破棄して、直前のコミット時の状態に戻す（元に戻せないので注意）
git restore <ファイル名>
